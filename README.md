# Sports Arbitrage Engine

A real-time odds streaming and arbitrage detection system.

## Structure

- `phase-1-discovery/` — Feasibility research, open source audit, stack evaluation, transaction window analysis
- `phase-2-build/` — TDD implementation (unlocked after Phase 1)
- `phase-3-rollout/` — Deployment and monitoring

## Working Style
Slow and deliberate early. Understand before building. Accelerate once the foundation is solid.
