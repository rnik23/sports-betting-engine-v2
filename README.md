- `phase_1_discovery/` — Feasibility research, open source audit, stack evaluation, transaction window analysis · [Discovery Doc](https://docs.google.com/document/d/1EKMKW0zAbbhkQqqxTNrWseKaHVUDOceSoG3JuVsfBcI/edit?usp=sharing)
